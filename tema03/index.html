Ejercicio 3

Coerción y comparaciones

function ejercicio3() {
  console.log("--- Ejercicio 3 · DANIEL MARTINEZ FERRERAS ---");
 
  console.log('"5" - 2 →', "5" - 2);
  console.log('"5" + 2 →', "5" + 2);
  console.log('"8" * 2 →', "8" * 2);
  console.log('true + 2 →', true + 2);
  console.log('"12" - 4 →', "12" - 4);
  console.log('"Nota: " + 7 →', "Nota: " + 7);
 
  console.log('5 == "5" →', 5 == "5");
  console.log('5 === "5" →', 5 === "5");
  console.log('0 == false →', 0 == false);
  console.log('0 === false →', 0 === false);
  console.log('null == undefined →', null == undefined);
  console.log('null === undefined →', null === undefined);
}

Con +, si hay una cadena, se unen los valores como texto. Con - o *, JavaScript intenta convertirlos a números. Por eso "5" + 2 da "52", pero "5" - 2 da 3.

=== comprueba el valor y el tipo sin convertirlos. Así se evita que 5 y "5" se consideren iguales. Las dos expresiones añadidas como ejemplos son "12" - 4 y "Nota: " + 7.
