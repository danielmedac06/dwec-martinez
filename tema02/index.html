¿Por qué comparten motor?

Muchos navegadores usan Chromium porque ofrece una base de código muy completa. Chrome, Edge y Opera usan Blink y V8, por lo que muchas páginas funcionan de forma parecida en ellos. Firefox utiliza Gecko y Safari utiliza WebKit, por lo que pueden existir algunas diferencias. Para desarrollar una web es importante probarla en diferentes navegadores para comprobar que todo funciona correctamente. También hay que tener en cuenta los móviles porque el navegador puede comportarse de otra forma.

Ejemplo de compatibilidad

He consultado Can I Use sobre CSS import attributes. La característica tiene diferencias de compatibilidad entre navegadores. Por ejemplo, actualmente no aparece soportada en Safari, mientras que sí aparece soportada en versiones recientes de Chrome y Edge.

Reflexión

Si un cliente me encarga una web, primero la probaría en Chrome y Firefox porque utilizan motores diferentes. También la probaría en un móvil para comprobar que el diseño se adapta correctamente. Después comprobaría Safari y Edge para detectar posibles diferencias de compatibilidad.
